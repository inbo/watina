# watina: Querying and Processing Data from the INBO Watina Data Warehouse

The R-package watina contains functions to query and process data from
the Watina database at the Research Institute for Nature and Forest
(INBO). This database primarily provides groundwater level and chemical
data, mainly from natural areas in Flanders (Belgium).

## Details

See the [Index](https://inbo.github.io/watina/reference/00Index.md) for
an overview of the available functions. Basic data retrieval functions
start with "`get_`".

Read the vignettes (linked by the
[Index](https://inbo.github.io/watina/reference/00Index.md)) to get
started with the package.

[`selectlocs_xg3`](https://inbo.github.io/watina/reference/selectlocs_xg3.md)
is a top-level function that allows to select locations based on
user-specified conditions on XG3 availability and XG3 series.

[`selectlocs_chem`](https://inbo.github.io/watina/reference/selectlocs_chem.md)
is a top-level function that allows to select locations based on
user-specified conditions on chemical data availability and properties.

For contributing, see the README on
[GitHub](https://github.com/inbo/watina/blob/master/README.md).
